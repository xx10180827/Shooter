# T13 AI 受击警觉、听觉调查与移动射击

日期：2026-09-29
状态：实现、UE5.5 编译及自动验证完成；2026-10-01 用户授权提交推送并进入下一阶段。逐项人工验收未单独回填。

## 1. 本轮范围

用户选择继续完善 AI：巡逻/返回巡逻、背后受击与附近开枪警觉、移动射击。沿用 T12 已验收的独立随机巡逻，也保留可切换的固定路线模式。此前建议的武器数据化、双武器、GAS 冲刺技能仍是候选，本轮不实施。

基线为已推送 develop 的 e6a92ab。用户额外菜单资产修改和个人笔记继续保留。

## 2. 行为流程

```text
随机巡逻
  ├─ 看到玩家 → 追踪 / 移动射击
  ├─ 受到玩家有效伤害 → 转向并调查伤害来源位置
  └─ 听到范围内玩家枪声 → 转向并调查枪声位置

调查固定事件位置
  ├─ 看到玩家 → 交战
  └─ 4 秒内未发现 → 恢复巡逻

交战时失去视线
  └─ 搜索最后可见位置，记忆超时后恢复巡逻
```

声音和伤害只记录事件发生时的位置。调查不会每帧读取墙后玩家的当前位置；只有原视野角、距离和无遮挡检查通过后才取得战斗目标。正在看见并交战的玩家优先于新的警觉事件。

仍使用 GAS 唯一伤害入口。上报受击不重复扣血；上报枪声不依赖是否播放声音或是否命中。只有成功发射并扣弹的一发才报告枪声，空弹、换弹和冷却拒绝不会报告。

## 3. 移动射击

敌人进入 12 米射程后允许一边接近一边开火：

| 参数 | 默认值 |
| --- | --- |
| 射程内接近速度 | 220 cm/s |
| 停步距离 Hold Distance | 450 cm |
| 重新跟进距离 Resume Distance | 600 cm |
| 射程外追踪速度 | 恢复角色原速度 |
| 枪声听觉范围 Hearing Range | 2400 cm |
| 调查时间 Investigation Duration | 4 秒 |

远近两个阈值用于避免在同一个距离边界不断启停。每次真正开火仍重新检查生命、射程、朝向和遮挡；被墙挡住时取消待发攻击并转入搜索。原攻击动画、枪声、可见子弹和单次伤害入口继续使用。

本版移动射击是接近、保持距离和跟进，不包含侧向走位、掩体或点射节奏。玩家主动贴近时敌人会停步，尚不主动后撤。

## 4. 实现分工

- ShooterAwarenessComponent：继承 UE 原生 AIPerceptionComponent，配置 Hearing 与 Damage 感知，把位置快照交给控制器。
- ShooterAIController：增加 Investigating 状态，协调调查、视野发现、交战、搜索及返回巡逻。
- ShooterCombatMovementComponent：只负责射程内移动和速度恢复，不修改伤害。
- ShooterDamageLibrary：有效非致死伤害后上报原生 Damage 感知。
- ShooterWeaponComponent：成功发射时报告原生 Hearing 事件。
- ShooterAwarenessSmokeSubsystem：显式测试参数下运行真实地图专项，正常游戏不注册测试 Tick。

新增 .h 与 .cpp 分别位于 Source/MyShoot/Public 和 Private 对应的 AI、Tests 目录，关键逻辑有中文注释。新状态追加在旧枚举末尾，保持原枚举值。

原生听觉的阵营过滤接收各类队伍，再按玩家身份筛选。原因是本项目未配置队伍 ID，不能依靠默认阵营关系识别玩家。当前范围听觉允许隔墙听见，不模拟墙体声学衰减；敌人队友的枪声不会引发玩家警觉。

## 5. 编辑器配置

打开 Boot_Shooter_controller：

- ShooterAwareness 组件：调整 Hearing Range、Investigation Duration。
- CombatMovement 组件：调整 Enable Moving Fire、Combat Move Speed、Hold Distance、Resume Distance。
- ShooterPatrol 组件：仍调整随机巡逻范围、速度和停留时间。

这是原生默认组件新增，使用本次编译结果重新打开编辑器后可见，无需重设角色父类或重新连接射击蓝图。原菜单修改保留。
