# T11：AI 视野、自动寻路与远程射击

日期：2026-09-28。状态：实现、构建、自动回归与实际地图验证完成；用户于 2026-09-29 授权提交推送并继续巡逻开发；逐项人工验收结果未单独填写。

## 1. 目标与原问题

原控制器已有 NavMesh 追踪、攻击前摇、冷却和 Visibility 遮挡检测，但原生 AttackRange 默认只有 220 cm，且发现目标是全向的。因此敌人往往追到很近才开枪。此次将发现距离、攻击距离和视野角分别配置，沿用既有 C++ 控制器与 GAS 伤害流程。

## 2. 当前行为

| 情景 | AI 行为 |
| --- | --- |
| 没有发现玩家 | Idle，保持待机；本阶段尚未增加巡逻路线 |
| 玩家在前方视野内、20 米以内、无遮挡 | 自动发现玩家并记录可见位置 |
| 已发现，距离超过 12 米 | Chasing，通过 NavMesh 自动接近 |
| 12 米以内且无遮挡 | 停止追赶，转向玩家，进入 Attacking；前摇完成后开枪 |
| 等待下一次攻击冷却 | 保持射击位置，不继续冲到玩家身边 |
| 玩家进入墙后或离开视野 | 取消前摇和攻击；Searching，沿导航前往最后看见的位置 |
| 3 秒内重新看见玩家 | 更新位置，按距离恢复射击或追踪 |
| 丢失视野超过 3 秒，或目标超过 30 米 | 清除目标并停止搜索；等待重新发现 |
| 玩家或 AI 死亡、暂停或结算 | 沿用原中断机制，停止射击和相关活动 |

发现、注视焦点与射击检测统一使用眼睛位置，避免近距离的朝向判定不一致。发现与射击均使用眼睛到目标眼睛的 Visibility 检测；视野通过方向向量点积判断。开火角度比发现角度窄，要求先面向目标。攻击结束时再次检查射程、朝向、遮挡与存活状态，玩家在前摇内躲进墙后可取消本次伤害。

AI 仍通过原 GAS 伤害入口扣血一次，动画、枪声和子弹在有效开火时触发。子弹模型为表现用途，不重复产生碰撞伤害。

## 3. 编辑器参数

打开 Boot_Shooter_controller → Class Defaults → Shooter / AI。

| 属性 | 当前值 | 含义 |
| --- | --- | --- |
| Detection Range | 2000 cm | 首次发现玩家的距离 |
| Lose Target Range | 3000 cm | 已发现目标的最大跟踪距离，避免发现边界反复切换 |
| Attack Range | 1200 cm | 可开火的最大距离 |
| Sight Half Angle | 60° | 左右各 60°，前方总视野角 120° |
| Fire Half Angle | 15° | 面向玩家的允许误差，达到此条件才进入有效攻击 |
| Sight Memory Seconds | 3 秒 | 遮挡后记住最后可见位置的时间 |
| Move Acceptance Radius | 75 cm | 导航到达容差，独立于射程；沿导航接近，战斗逻辑在进入 12 米内时停止移动 |

伤害、射速、前摇、动画、声音和子弹类保留现有设置。默认仍是单发节奏，不在此次加入点射或自动换弹。

项目使用厘米为单位。修改 12 米射程应填写 1200，不是 12。视野不是穿透墙体的距离圆：范围、方向和无遮挡必须同时满足。

## 4. 实现与文件

- Public/AI/ShooterAIController.h、Private/AI/ShooterAIController.cpp：发现、射击条件、导航追踪和短时位置记忆；保持 Public/Private 分置并添加中文注释。
- 既有 EShooterAIState 在末尾追加 Searching，保留旧枚举值顺序，避免破坏蓝图序列化。
- 只有可见时才更新 LastSeenLocation。丢失视野撤销 MoveToActor 和目标 Focus，改用 MoveToLocation + 固定位置 Focus；重新发现时撤销旧搜索路径。
- 导航请求低频重试，不逐帧重新构建路径。无法到达时不瞬移、不绕过 NavMesh，也不穿墙扣血。
- ShooterAIRangedSetup 编辑器命令：默认只读，-Apply 写入上述指定参数，-Verify 验证保存结果；不会删除或重连原蓝图节点。
- 修改前控制器资源与源码备份：Saved/T11/Backup。

## 5. 验证

已完成 UE5.5 Editor 构建与保存后参数校验。真实地图验证通过：初始距离 1733.0 cm，敌人实际移动 638.6 cm，首次开火距离 1098.2 cm，玩家血量 100 → 90；射击后保持位置并遵守冷却。记录：Saved/T11/MapSmoke/Game3.log、Result.txt 与 02-RangedShot.png。最终 13 项 MyShoot 自动测试全部通过，0 失败、0 未运行；报告：Saved/T11/ReleaseAutomationReport/index.json。回归测试包括背后不自动发现、10 米射击无需接触、超射程追踪但不扣血、遮挡中断、最后可见位置与记忆过期、重新发现，以及原死亡和多敌人行为。

真实地图检查通过显式参数 -ShooterAIRangedSmoke 运行，使用 bloodstrike 现有 NavMesh 自动挑选可见且可达的远距离位置，验证实际路径移动、首次远程扣血与停步冷却。正常游戏不会运行测试流程或移动角色。

测试距离时注意地图里的敌人朝向；站在敌人背后不会触发初次视觉发现。可以在编辑器中按 P 查看绿色 NavMesh 覆盖区域；路径受可走区域约束。游戏运行时 P 保持原有暂停功能。

## 7. 后续建议顺序

1. 巡逻点、停留和回到巡逻：让未发现玩家时也有行为。
2. 短点射、停顿和可配置散布：调整交战节奏与命中容错；若加入散布，应同步实际射线和 GAS 命中判定，不能只偏转子弹特效。
3. 掩体与换位：寻找可达遮挡点，露头射击、退回掩体。
4. 受击反应和听觉警觉：补充背后受到攻击、听到枪声时的目标发现来源。
