# T20 命中反馈与击杀确认

日期：2026-10-06。用户授权开始四项基础打击感：四条短线、命中/击杀确认音、受击血雾、用户击杀图标。架构要求表现可替换，伤害结算继续使用 GAS。双杀、多杀复用同一图标并显示动态倍数。

## 第一版行为

- 只有实际扣血才确认命中；打空、墙体、尸体、无敌拒绝不触发成功反馈。
- 普通命中显示四条白色斜短线，中心留空，腰射准星和开镜红点保留。默认 0.16 秒淡出。
- 致死命中变金色，默认 0.30 秒；金色尚未结束时，后续普通命中不会覆盖成白色。
- 图标使用 SourceArt/UI/KillIcon_Transparent.png，原图保留。PNG 实际为 1254×1254，边角 alpha 为 0。
- 徽章位于屏幕中央偏下（Y=0.84），基准 192 UI 单位，位于现有体力条下方；0.70→1.15→1.00 缩放，0.85 秒后淡出。
- 单杀显示 KILL；3 秒内再次击杀累计 ×2、×3…，每次有效击杀刷新窗口。超过 3 秒后下一次重新从 1 开始。
- 同一枪多目标击杀直接增加多个计数；重复 ShotId 拒绝，死目标不会再次生成击杀结果。
- 同枪所有弹丸只播放一次普通/击杀确认音；致死优先，播放新确认音前停止旧音，避免叠加。确认音不生成 AI 听觉事件。
- 血雾在真实目标命中位置沿表面法线向外短促喷散，每目标最多一处、每枪默认最多 2 处、同时最多 8 处。材质/粒子/大小可替换。
- 暂停、失败、返回菜单、失去角色和销毁时清理反馈；胜利页保留最后一枪确认的短暂动画，避免最后一个敌人没有击杀提示。
- 本轮聚焦四项基础反馈。敌人新受击动作、墙面/金属分类弹着、玩家受伤方向是后续增强项。

## 配置资源

统一入口：Content/Feedback/DA_CombatFeedback。

| 属性 | 默认/用途 |
| --- | --- |
| KillIcon | T_KillIcon，用户透明骷髅徽章 |
| HitSound / KillSound | SW_HitConfirm / SW_KillConfirm，可分别替换 |
| HitVolume / KillVolume | 0.55 / 0.45 |
| HitDuration / KillMarkerDuration | 0.20 / 0.30 秒 |
| KillIconDuration / IconSize / IconScreenY | 0.85 秒 / 192 / 0.84 |
| MultiKillWindow | 3 秒，以游戏时间计算 |
| BloodEffect | P_BloodBurst |
| MaxBloodBurstsPerShot / MaxActiveBloodBursts | 2 / 8 |
| BloodScale | 1.0 |

血雾是独立的 UE CPU Sprite 粒子资产（Cascade），包含 5 个柔边云团与 8 个小液滴，0.16–0.34 秒生命周期、一次性喷发、自动销毁；不是运行时把原枪口烟雾直接染红。材质 M_BloodBurst 使用程序化不规则柔边遮罩和粒子颜色/透明度，无须额外生成血雾图片。后续如果升级 Niagara，只需扩展表现配置/生成层，伤害与单发结果结构保持独立。

确认音由 C++ 编辑器工具确定性合成，短点击音与双音击杀确认，分别约 0.075 / 0.20 秒。WAV 源文件保留在 SourceArt/Audio/SW_HitConfirm.wav 和 SW_KillConfirm.wav，最终听感由用户试听验收。

## 代码职责

所有头文件/实现按 Public / Private 分离，关键职责有中文注释。

- Combat/ShooterCombatResult：详细目标伤害结果与单发结果；记录实际伤害、是否本次致死、命中信息与 ShotId。
- Combat/ShooterDamageLibrary：ResolveGASDamage 复用原 GE 结算，以结算前后血量差得到结果；原 ApplyGASDamage bool 蓝图接口保留。
- Weapons/ShooterWeaponComponent：霰弹按目标汇总后逐目标结算，再广播 OnShotResolved。原 OnShotFired 开火表现接口保留，不把 BlockingHit 当作成功伤害。
- Combat/ShooterCombatFeedbackComponent：本地控制器组件，订阅玩家武器；合并音效/计数、限制粒子预算、管理清理。不重新扣血或修改武器数值。
- UI/ShooterCombatFeedbackWidget：只绘制命中线、徽章与倍数，不处理战斗规则。
- Combat/ShooterFeedbackConfig：共享配置资产，方便替换资源和调参。未来可增加按连杀数选择图标/音效的映射，而无需更改 GAS 结算。
- Player/ShooterPlayerController：创建/订阅/销毁反馈组件和 HUD，处理对局状态；面板不接收鼠标输入。
- ShooterFeedbackSetupCommandlet：导入图标、合成并导入短音频、构建独立粒子与配置。只处理 /Game/Feedback，未重存已有地图和蓝图。-Verify 只检查资源引用。
- DefaultGame.ini 显式烘焙 /Game/Feedback，覆盖原生软路径加载配置以及它引用的图标/音频/粒子。

目前接入现有单机本地玩家射击链路；没有宣称实现多人复制的命中确认。
